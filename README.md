# Empório Frios Pastelaria PBA — projeto demonstrativo

Site estático em HTML, CSS e JavaScript. Abra `index.html` no navegador para visualizar.

## Personalização
- `index.html`: textos, seções, endereço e links.
- `styles.css`: identidade visual e responsividade.
- `script.js`: produtos, preços ilustrativos, carrinho e configuração do WhatsApp.

## Antes de publicar
1. Em `script.js`, preencha `STORE.whatsapp` com DDI + DDD + número, apenas dígitos.
2. Confirme endereço, horário, telefone, preços, produtos e opções de entrega com o proprietário.
3. Troque imagens ilustrativas por fotos reais, se fornecidas.
4. A seção de avaliações fica mais abaixo, após a localização. Não há comentários públicos: os cartões são espaços reservados para avaliações reais selecionadas pela loja, com autorização. Substitua os textos ilustrativos antes de apresentar como depoimentos reais.
5. Confirme o endereço exato do mapa antes da publicação.

Preços, fotos, depoimentos de exemplo e alguns textos são provisórios. O carrinho prepara uma mensagem para enviar ao WhatsApp, mas só funcionará depois que o número da loja for configurado.
